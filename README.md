# Secure Authentication System

A secure authentication web application built using Flask and SQLite.

## Features
- User Registration
- User Login
- Password Hashing using Flask-Bcrypt
- Session Management
- Responsive UI

## Technologies Used
- Python
- Flask
- SQLite
- HTML
- CSS

## Installation

```bash
pip install flask flask-bcrypt
python app.py
```
